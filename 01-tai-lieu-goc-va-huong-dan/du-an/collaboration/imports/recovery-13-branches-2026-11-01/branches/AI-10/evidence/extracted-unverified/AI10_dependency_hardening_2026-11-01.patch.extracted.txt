+# AI-10 — Kiểm đầy đủ phụ thuộc Node/JSON và chứng thực Git HEAD tại máy
+
+**Ngày:** 01/11/2026
+**Phạm vi:** `collaboration/parallel-research/submissions/AI-10/`
+**Mốc nguồn đối chiếu từ lần đồng bộ gần nhất:** `3fba778df2db68cd0fdbb472a271b1322dcc66ae` trên `codex/ai-10-tam-thuc` (CHƯA thể xác nhận lại HEAD thời điểm đóng gói).
+**Trạng thái:** Bản vá hoàn thiện, chạy kiểm tra cục bộ; **chưa đẩy GitHub** do kết nối GitHub trả HTTP 403 `Sorry. Your account was suspended` khi đọc repo, file và PR #11.

+## 1. Vì sao cần bổ sung
+
+`TEST_MANIFEST.json` của vòng trước đã ghim byte/SHA-1 Git cho **22 tệp `test-*.mjs`**, nhưng không kiểm tra ngay từ đầu rằng **các mô-đun `.mjs` được import và JSON nguồn được đọc có còn đầy đủ, thuộc thư mục AI-10 và giữ nguyên byte được commit hay không**. Điều này có thể tạo ra khoảng trống khi test có SHA đúng nhưng một phụ thuộc đổi nội dung, hoặc khi kiểm thử chạy trên checkout thiếu dữ liệu.
+
+Bản vá này thêm hai lớp riêng biệt, tránh nhập nhằng về phạm vi chứng thực:
+
+1. **Kiểm tra closure nguồn không thực thi** (`ai10-dependency-audit.mjs`): dùng `node:vm.SourceTextModule` trong tiến trình phân tích cách ly để lấy các `import`/`export from` tĩnh; lần theo các URL tệp `new URL('./file.json', import.meta.url)` dạng hằng; đi xuyên qua các mô-đun nội bộ; từ chối thiếu tệp, import package ngoài `node:`, vượt phạm vi AI-10, symlink thư mục/tệp, nhập động `import()` hoặc `require()`. Xuất SHA Git **quan sát được** cho từng tệp, song không mạo nhận đã so với commit.
+2. **Kiểm tra HEAD Git tại máy, tùy chọn** (`ai10-git-tree-audit.mjs`): so tất cả tệp đã phát hiện với các blob có trong **cây commit `HEAD` tại checkout**, không chỉ so tệp test. Bắt được tệp `.mjs`/JSON sửa nhưng chưa commit, kể cả sửa có cùng kích thước và tệp mới được import nhưng chưa commit. **Không truy cập mạng** và không xác thực HEAD đó là commit chính thức trên máy chủ GitHub.
+
+Trình chạy `run-ai10-strict.mjs` được mở rộng với hai lựa chọn **`--verify-git-head`** và **`--run-git-head`**, ngoài ba lựa chọn trước. `--run` giữ khả năng chạy trên archive không có `.git`, nhưng bảo đảm inventory test và closure nguồn đều hợp lệ trước khi chạy. Người cần bảo đảm byte đối với commit tại máy phải sử dụng `--run-git-head`.

+## 2. Ranh giới phương pháp
+
+- Dùng trình phân tích cú pháp Node `vm.SourceTextModule` (cần Node.js 20+/22 và cờ `--experimental-vm-modules` do tiện ích gọi nội bộ), **không evaluate module**, không chạy app/engine khi kiểm closure. Việc kiểm thử riêng bằng `node --test` diễn ra sau các điều kiện chắn.
+- Kiểm nhập tĩnh và `new URL` dạng chữ hằng, không bao phủ mọi I/O runtime được ghép chuỗi, ví dụ `readFileSync(dynamicPath)`, biểu thức trong template literal hay code sinh ra bằng `eval`. Trả `dynamicRuntimeReadsCovered=false`; không gọi đây là chứng nhận toàn diện mọi phụ thuộc runtime.
+- Nếu thiếu Git metadata, `--verify-git-head` trả lỗi có mã `GIT_REPOSITORY_NOT_FOUND` thay vì tự giả định cây Git đúng.
+- Một Git HEAD được xác nhận **chỉ là HEAD tại máy**. Mức `remoteCommitAuthenticated=false`, `historicalSourcesAuthenticated=false`, `consumerReady=false` vẫn giữ nguyên. Không có bất cứ thay đổi quy tắc lịch, Tứ khóa, Sơ truyền/Tam truyền, hoặc dữ liệu phát hành.

+/**
+ * AI-10: static, fail-closed dependency *presence and scope* preflight.
+ * Never executes examined modules; never calls the app/engine or the network.
+ * This is a structural import scan, not a JavaScript compiler or a byte lock.
+ * Static relative import/export and new URL('...',import.meta.url) literals
+ * are traversed transitively. Runtime-generated I/O cannot be proven here.
+ */
+import {readFileSync,lstatSync,realpathSync} from 'node:fs';
+import {resolve,relative,dirname,sep,isAbsolute} from 'node:path';
+import {spawnSync} from 'node:child_process';
+import {gitBlobSha} from './ai10-test-audit.mjs';
+
+const URL_LITERAL=/^new\s+URL\s*\(\s*(['"])([^'"\r\n]+)\1\s*,\s*import\.meta\.url\s*\)/;
+const DYNAMIC_IMPORT=/\bimport\s*\(/;
+const REQUIRE_CALL=/\brequire\s*\(/;
+// node:vm.SourceTextModule parses import declarations without evaluating code.
+// Isolate it in a short-lived, no-network child because the VM parser flag is
+// still experimental on Node 20/22. Syntax errors fail the preflight closed.
+const STATIC_PARSER=String.raw`const vm=require('node:vm');
+try {const m=new vm.SourceTextModule(require('node:fs').readFileSync(0,'utf8'),{identifier:'AI-10 source preflight'});
+ process.stdout.write(JSON.stringify(m.dependencySpecifiers));}
+catch(e){process.stderr.write(String(e?.message||e));process.exitCode=2;}`;
+function staticallyParsedImports(source){
+ const p=spawnSync(process.execPath,['--experimental-vm-modules','--no-warnings','-e',STATIC_PARSER],
+  {input:source,encoding:'utf8',timeout:10000,maxBuffer:1024*1024});
+ if(p.error||p.status!==0)throw new Error(String(p.error?.message||p.stderr||'Source parser failed'));
+ const result=JSON.parse(p.stdout);
+ if(!Array.isArray(result)||result.some(s=>typeof s!=='string'))throw new Error('Invalid source parser result');
+ return result;
+}
+/** Replace strings, comments and templates with spaces without examining them
+ * as live code. This deliberately does not claim to resolve runtime I/O in
+ * template interpolations. Static imports are parsed with the VM compiler. */
+function scanStaticURLLiterals(source){
+ const refs=[],sanitized=source.split('');
+ const blank=(start,end)=>{for(let j=start;j<end;j++)if(source[j]!=='\n')sanitized[j]=' ';};
+ for(let i=0;i<source.length;){
+  if(source.startsWith('//',i)){
+   const end=source.indexOf('\n',i);const j=end<0?source.length:end;blank(i,j);i=j;continue;
+  }
+  if(source.startsWith('/*',i)){
+   const end=source.indexOf('*/',i+2);const j=end<0?source.length:end+2;blank(i,j);i=j;continue;
+  }
+  if(source[i]==='\''||source[i]==='"'||source[i]==='`'){
+   const quote=source[i];let j=i+1;
+   for(;j<source.length;j++){
+    if(source[j]==='\\'){j++;continue;}
+    if(source[j]===quote){j++;break;}
+   }
+   blank(i,j);i=j;continue;
+  }
+  if(source.startsWith('new',i)){
+   const m=URL_LITERAL.exec(source.slice(i));
+   if(m&&(!i||!/[\w$]/.test(source[i-1]))){refs.push(m[2]);}
+  }
+  i++;
+ }
+ return {refs:[...new Set(refs)],sanitized:sanitized.join('')};
+}
+const STATIC_FILE_TYPES=new Set(['.mjs','.js','.json']);
+const deepFreeze=o=>Object.freeze(o);
+function problem(code,path,detail){return deepFreeze({code,path,detail});}
+function within(root,target){
+ const rel=relative(root,target);
+ return rel!==''&&!rel.startsWith('..'+sep)&&rel!=='..'&&!isAbsolute(rel);
+}
+function checkPath(root,file){
+ if(!within(root,file))return 'OUTSIDE_AI10';
+ const segments=relative(root,file).split(sep);
+ let cur=root;
+ for(const segment of segments){
+  cur=resolve(cur,segment);
+  let stat;
+  try{stat=lstatSync(cur);}catch(e){return e?.code==='ENOENT'?'MISSING_DEPENDENCY':'UNREADABLE_DEPENDENCY';}
+  if(stat.isSymbolicLink())return 'DEPENDENCY_SYMLINK';
+ }
+ if(!realpathSync(file).startsWith(realpathSync(root)+sep))return 'OUTSIDE_AI10';
+ if(!lstatSync(file).isFile())return 'NOT_REGULAR_FILE';
+ return null;
+}
+function allowedSpecifier(spec){
+ if(spec.startsWith('node:'))return 'builtin';
+ if(spec.startsWith('./')||spec.startsWith('../'))return 'relative';
+ return 'unsupported';

+/**
+ * @param {string} root  Absolute or relative path to AI-10 submission folder.
+ * @param {string[]} tests Paths RELATIVE to root, already vetted by test manifest.
+ * @returns {{pass:boolean,files:readonly object[],issues:readonly object[]}}
+ */
+export function auditAI10DependencyClosure(root,tests){
+ if(typeof root!=='string'||root.length===0||!Array.isArray(tests)||
+    tests.some(p=>typeof p!=='string'||p.length===0))
+  throw new TypeError('Explicit AI-10 root and array of test paths required');
+ const absRoot=resolve(root);
+ const issues=[],visited=new Set(),pending=[];
+ for(const test of tests){
+  const abs=resolve(absRoot,test);
+  if(!within(absRoot,abs)||!/^test-[A-Za-z0-9_.-]+\.mjs$/.test(test.split(/[\\/]/).at(-1))){
+   issues.push(problem('BAD_TEST_PATH',test,'Only relative AI-10 test-*.mjs paths are permitted'));
+  } else pending.push(abs);
+ }
+ const entries=[];
+ while(pending.length){
+  const file=pending.pop();
+  if(visited.has(file))continue;
+  visited.add(file);
+  const rel=relative(absRoot,file).split(sep).join('/');
+  const invalid=checkPath(absRoot,file);
+  if(invalid){issues.push(problem(invalid,rel,'Cannot inspect this dependency'));continue;}
+  let bytes;
+  try{bytes=readFileSync(file);}catch(e){issues.push(problem('UNREADABLE_DEPENDENCY',rel,String(e?.code||e?.message)));continue;}

+  entries.push(deepFreeze({path:rel,kind,bytes:bytes.length,gitBlobSha:gitBlobSha(bytes)}));
+  if(kind==='fixture')continue;

+  let staticImports;
+  try{staticImports=staticallyParsedImports(content);}
+  catch(e){issues.push(problem('SOURCE_PARSE_ERROR',rel,e.message));continue;}

+  // Dynamic imports are detected only in the token-like, non-string parts of
+  // the source. Runtime imports in template interpolations are NOT certified.
+  if(DYNAMIC_IMPORT.test(sanitized))issues.push(problem('DYNAMIC_IMPORT_UNINSPECTED',rel,'Dynamic import needs manual review'));
+  if(REQUIRE_CALL.test(sanitized))issues.push(problem('REQUIRE_UNINSPECTED',rel,'CommonJS require needs manual review'));
+  for(const spec of [...new Set([...staticImports,...refs])]){
+   const type=allowedSpecifier(spec);
+   if(type==='builtin')continue;
+   if(type==='unsupported'){issues.push(problem('EXTERNAL_SPECIFIER',rel,spec));continue;}
+   const target=resolve(dirname(file),spec);
+   // A literal directory URL may be used to locate the AI-10 root itself,
+   // e.g. new URL('../', import.meta.url) in a test; it is not a file import.
+   // Reject directory references that escape the audit boundary.
+   if(spec.endsWith('/')){
+    if(target!==absRoot&&!within(absRoot,target))
+     issues.push(problem('OUTSIDE_AI10',rel,spec));
+    else if(target!==absRoot){
+     const invalid=checkPath(absRoot,target);
+     if(invalid==='NOT_REGULAR_FILE')continue;
+     if(invalid)issues.push(problem(invalid,rel,spec));
+    }
+    continue;
+   }
+   if(!/[.]mjs$|[.]js$|[.]json$/.test(target)){
+    issues.push(problem('UNSUPPORTED_EXTENSION',rel,spec));continue;
+   }
+   const extension=target.slice(target.lastIndexOf('.'));
+   if(!STATIC_FILE_TYPES.has(extension)){
+    issues.push(problem('UNSUPPORTED_EXTENSION',rel,spec));continue;
+   }
+   if(!within(absRoot,target)){
+    issues.push(problem('OUTSIDE_AI10',rel,spec));continue;
+   }
+   pending.push(target);
+  }
+ }
+ entries.sort((a,b)=>a.path.localeCompare(b.path,'en'));
+ issues.sort((a,b)=>a.path.localeCompare(b.path,'en')||a.code.localeCompare(b.code,'en'));
+ return deepFreeze({catalogue:'AI-10',pass:issues.length===0,
+  testEntries:tests.length,localSourceFileCount:entries.length,
+  moduleCount:entries.filter(x=>x.kind==='module').length,
+  fixtureCount:entries.filter(x=>x.kind==='fixture').length,
